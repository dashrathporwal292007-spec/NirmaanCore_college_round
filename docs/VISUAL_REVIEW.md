# Editorial review and screenshot comparison

Reference screenshots live in `screenshots/reference/`; Nexus screenshots live beside them in `screenshots/editorial/`. Open `screenshots/comparison.html` for a side-by-side view. Nexus captures include 1440×900, 1280×720 and 390×844, plus full-page versions.

## What improved

The initial Agent statement now has a clear condensed / italic-serif contrast and substantial space. After planning, it shrinks and the operational receipt takes priority. The page stays black, with color reserved for decisions and recorded effects. Dashed receipt framing and the decorative tilted stamp were removed in favor of hairlines.

The first review found too much mobile chrome and overly dominant webinar titles. Worker controls now share the top bar; the role switcher lives in the full-screen menu, while planner source and simulation disclosure stay visible. Webinar detail opens with a short statement followed by the real webinar title. The final keyboard review found native Tab focus could escape toward browser chrome; explicit first/last control wrapping fixes that.

Rules use numbered, large rows with verified explanations, mouse hover, keyboard focus, single-tap activation and direct links from recorded IDs. Runs use the same editorial hierarchy with actual instructions revealed on hover/focus and permanently readable under reduced motion or touch. Live uses the real trace and a selected-contact event ticker, with structural lines extended to the page edges.

## Where Nexus still falls short of the reference

Ownitt has richer art direction and more varied section compositions, supported by custom fonts, imagery and film. Nexus's free fonts approximate the condensed / serif contrast but do not have the same letterforms. Its receipt, evidence and permission controls create more density than an agency landing page. The post-plan screen consequently requires scrolling to read every effect and approve; it favors legibility over squeezing seven effects into a single viewport.

The reference's index and territories contain more elaborate image and layered-type reveals. Nexus uses simpler text expansion because rule explanations and run summaries must remain readable, accessible and backed by recorded data. This is a functional editorial application, not a reproduction of the reference's visual complexity.

No reference logo, monogram, parentheses motif, copy, image, video or font was put into the product. Installed font licenses were checked: all four are SIL Open Font License 1.1 and are bundled through next/font/local.
